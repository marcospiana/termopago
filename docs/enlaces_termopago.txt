COMO FUNCIONA (resumen)
=====================================================================
HAY DOS SISTEMAS conviviendo:
  * MQTT (nuevo): inflado01, aspiradora01, soplado01. El ESP mantiene una
    conexion MQTT y el backend le PUSHEA la activacion al instante. Sin
    polling -> no se cuelga. El QR vence a los 15 min y se re-arma solo con
    el heartbeat (cada 60s, re-arma si pasaron +10 min). Si el equipo se cae
    (LWT "offline") se cancela el QR de esa caja (y de sus hermanas del mismo
    ESP) para que nadie pague una maquina muerta; al volver se re-arma solo.
  * HTTPS polling (viejo): estacion02 y el resto. El ESP pollea cada 4s. El
    QR vence a los 30 min y se renueva cada 20. (Este es el que se cuelga por
    fragmentacion de RAM; por eso migramos estacion01 a MQTT.)
- Pago aprobado -> webhook -> orden en la base -> se activa el equipo (push
  MQTT o proximo polling segun el sistema).
- INFLADO = pulso (un toque, la maquina corre su ciclo). ASPIRADORA/SOPLADO =
  sostenido (el esclavo Nano sostiene el rele y cuenta el tiempo).
- Si el equipo esta sin conexion y alguien paga, a los ~5 minutos se le
  devuelve el dinero automaticamente (estado "reembolsada").
- Si se corta la luz a mitad de un servicio, al volver el equipo retoma con
  el tiempo restante (el conteo va en tiempo real desde el pago).
- Ahora ademas hay ALERTAS por Telegram si un equipo se cae (ver arriba).
- Monto minimo de MP para ordenes QR: usar $50 o mas.

PENDIENTES / DECISIONES CON EL CLIENTE:
- Recargo por credito: el QR no permite bloquear tarjeta de credito,
  pero se puede publicar el precio con el costo del credito incluido
  y aplicar descuento automatico para debito/dinero en cuenta.
  Implementacion lista para agregar cuando el cliente decida.
- Upgrade monedero: el C-10 ECO-2 no acepta credito externo; si el
  cliente quiere el tiempo de QR en el display Somyc, cambiar a
  C-10 ASM (entrada billetero) + software Nexus.
- Estadisticas para el cliente: pagina propia con solo sus maquinas.
- OAuth marketplace: backend listo, falta cargar MP_CLIENT_ID,
  MP_CLIENT_SECRET y FEE_PORCENTAJE en Railway + URL de redireccion
  /oauth_callback en el panel de MP.
